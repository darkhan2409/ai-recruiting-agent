🤖 AI Recruiting Agent

Тестовое задание для разработчика

🎯Цель

Создать прототип ИИ-агента, который помогает рекрутеру обрабатывать резюме, сопоставлять их с вакансиями и рекомендовать подходящих кандидатов.

📋Входные данные

📄 Резюме кандидатов

  • Приходят на e-mail: cv@company.com
  • Формат: какой угодно кандидатам
  • Автоматическое получение из почтового ящика

💼 Описание вакансий

  • Хранятся в текстовом виде
  • Содержат: требования, обязанности, стек технологий
  • Могут быть в отдельной папке или базе

⚙️Требования к решению

1. Интеграция с почтой

  • Подключение к почтовому ящику (IMAP/SMTP)
  • Автоматическое скачивание новых резюме
  • Сохранение в локальное хранилище

2. Обработка резюме и вакансий

  • Парсинг в структурированный формат: навыки, опыт, образование
  • NLP-подходы: токенизация, эмбеддинги, NER
  • Извлечение ключевых слов

3. Модель сопоставления

Реализовать три подхода:

1. Семантическое сравнение

Эмбеддинги (Sentence-BERT / USE / HuggingFace)

Метрика: cosine similarity

2. TF-IDF + ML-классификатор

Базовый метод для сравнения результатов

3. LLM (Large Language Model)

OpenAI GPT, HuggingFace LLaMA, Mistral

Prompt: Сопоставление с объяснением релевантности 0-1

4. Агент

  • Сервис на FastAPI/Flask
  • Поддержка нескольких языков (русский + английский)
  • Принимает job_id или текст вакансии
  • Возвращает топ-5 релевантных кандидатов
  • REST API: GET /recommendations?job_id=123
  • Фронт на Streamlit
  • Использование Docker для упаковки решения

5. Документация

  • Jupyter Notebook или Markdown-отчёт
  • Описание архитектуры и этапов обработки
  • Примеры работы модели и API

🚀Бонус

  • Объяснения от агента с помощью LLM
  • Пайплайн автоматического обновления
